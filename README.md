# SALESMAN-DASHBOARD-DATASET

Salesman analytis dashboard
This project focuses on analyzing sales data and presenting meaningful business insights through an interactive dashboard built using Microsoft Power BI.

✨ Key Features

- Monthly Sales Trend Analysis
- Top 5 Customers by Revenue
- Sales vs. Cost by Product
- Orders Over Time
- Profit and Revenue Analysis
- KPI Cards for Key Performance Indicators
- Interactive Date Slicer for filtering data

🛠️ Tools Used

- Microsoft Power BI
- Microsoft Excel

🎯 Project Objective

The objective of this project is to transform raw sales data into meaningful visual insights, helping users understand sales performance, customer contributions, product profitability, and business trends.
